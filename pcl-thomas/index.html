PCL Thomas455 修改版

第三方基于 PCL 修改 · Minecraft: Java Edition 启动器 · 当前版本 2.99.1.0

让开源版 PCL 重新能用：恢复游戏下载、主题个性化、本地凭据与自建仓库自动更新。

查看源码 下载最新版 上游 PCL

这是什么

PCL（Plain Craft Launcher）是一款 Minecraft: Java Edition 启动器。开源发布的这份源码在功能上做了一些限制，本页介绍的是我在自己机器上维护的一个修改分支：让它可以正常编译，并把几个被移除的功能恢复回来。

基于上游 2.99.0.0 版本源码（除换行符外与上游逐字节一致），所有改动都在 git 提交历史里，可逐条查看与回滚。

第三方修改版声明：本程序是第三方基于 PCL 独立进行二次创作的产物，与 PCL 官方（龙腾猫跃 / 成都瓜皮龙科技有限公司）无关，不代表官方立场，也未经官方背书。

做了哪些改动

修复编译失败

上游 MeloongCore 子模块在 zip 下载后是空目录，直接编译会报 MSB3202 / NU1104。补全子模块后还发现必须用 Visual Studio 自带 MSBuild——用 dotnet build 会炸出 500+ 个 BC30506（旧式 VB.NET + WPF 工程不支持 SDK 版 MSBuild）。

构建

恢复游戏下载

上游用 RestrictMcDownload = True 下线了下载，但下载链路本身完整保留。改为 False 后恢复：原版 / Forge / Fabric / NeoForge / OptiFine / LiteLoader 安装、整合包安装、实例修改中的版本切换。下载源未改动，仍为 BMCLAPI 与 Mojang 双源。

下载安装

恢复主题个性化

上游删除了「主题 ID → 配色」的映射表并用赞助校验锁死了大部分主题。本分支补回 15 个主题的 HSL 预设，解除解锁限制，并把自定义主题的色调 / 饱和度 / 亮度 / 渐变四个滑块重新接回渲染。

个性化主题

凭据编进程序

微软 Client ID、CurseForge Key、更新仓库在编译时注入，装好即用、不用自己填。真值放在被 .gitignore 排除的 ModSecretBuild.vb 中，仓库只提交模板；该文件不存在时工程照常编译。官方版同样内嵌这些值，只是通过 GitHub Actions Secrets 注入。

凭据构建

CurseForge 优雅降级

未配置 API Key 时，资源搜索自动只用 Modrinth 并提示一次，不再撞 403；配置后 CurseForge 搜索 / 下载 / 整合包全部可用。

CurseForgeModrinth

自建仓库更新

上游更新走官方签名 CDN。本分支改为查询自己 GitHub 仓库的 Release：tag 当版本号比较，有 exe 附件就下载 → --update 协议等旧进程退出 → 覆盖 → 重启；无附件则跳转 Release 页面。

更新GitHub API

移除百宝箱入口

「更多 → 百宝箱」在上游源码里就没实现，点进去只会提示“开源内容中不包含百宝箱功能”。本版直接把这个入口去掉，顺手也移除了设置里对应的“隐藏百宝箱”复选框，避免留下一个点了没反应的按钮。

如何构建

需要 Visual Studio（含 .NET 桌面开发 / VB 工作负载）与 .NET Framework 4.8 目标包。

# 1. 克隆（记得带上子模块）
git clone --recurse-submodules https://github.com/Thomas455/PCL-Thomas.git

# 2. 还原 NuGet 包
dotnet restore PCLCS/PCLCS.csproj

# 3. 用 Visual Studio 的 MSBuild 编译（不要用 dotnet build）
msbuild "Plain Craft Launcher 2\Plain Craft Launcher 2.vbproj" -p:Configuration=Release

产物位于 Plain Craft Launcher 2\bin\Plain Craft Launcher 2.exe。

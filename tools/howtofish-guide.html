渔力全开 存档工具 使用教程

How to Fish（Dazed Games）存档编辑：读取 / 修改 / 写回，全程浏览器本地处理

1. 存档在哪 2. 载入存档 3. 编辑功能 4. 保存生效 5. 常见问题

1. 存档在哪里

游戏存档在（AppData 默认隐藏，直接在文件管理器地址栏粘贴回车即可）：

%USERPROFILE%\AppData\LocalLow\Dazed Games\How to Fish\Saves

本机绝对路径示例：C:\Users\Windows 10\AppData\LocalLow\Dazed Games\How to Fish\Saves

目录里的文件

  • 你的存档名.txt（如 WwW.txt）—— 进度存档：物品、金钱、玩家、岛屿等进度数据
  • local.txt —— 外观存档：角色外观、生物图鉴、皮肤解锁、设置
  • .bak / .backup 后缀 —— 备份文件，游戏不读取，可放心保留
💡 游戏只读取「你的存档名.txt」和「local.txt」两个文件。备份文件不会被读取，改坏了可以用备份还原。

2. 载入存档（三种方式）

1
📁 扫描存档目录（推荐）

点「扫描存档目录」→ 在弹窗中导航到 Saves 目录并选择 → 列出全部存档（自动识别进度/外观类型），点「导入编辑」一键载入。授权一次后，下次打开页面自动扫描，无需再操作。

2
打开存档（可写回原文件）

直接选择 WwW.txt / local.txt 文件。这种方式拿到「写回原文件」权限，修改后可直接覆盖保存。

3
拖入 / 选择文件

把存档文件拖进虚线框，或点击选择。这种方式只能「下载修改后文件」，需手动替换回 Saves 目录。

💡 想改完直接保存到原文件，就用「打开存档」或「目录扫描」方式载入；只是看看或下载修改版，用拖入即可。

3. 编辑功能

进度存档（WwW.txt 类型）

  • 存档级数值：金钱、难度、游戏时长、雷达/烤架开关、引擎、船皮肤
  • 每个玩家独立区块：生命/饱食/额外槽位 + 完整物品栏 + 鱼饵持有量（16 种带名称）
  • 物品栏：显示全部槽位（基础 3 + 额外槽位），空槽位点下拉添加物品；皮肤/锋利度/瞄准镜/枪口/弹药等级/扩容/激光按物品类别自动启用；生物类物品可编辑烹饪度、投注倍数、重量、击杀倍率、闪光
  • 鱼饵：16 种鱼饵的持有数量，直接改数字

外观存档（local.txt 类型）

  • 帽子/服装/配饰外观索引（下拉选择）
  • 豆人形态、X/Y 轴反转开关
  • 生物图鉴：逐项勾选普通击杀 / Drip 击杀
  • 一键解锁：全部船皮肤（14 款）、图鉴全收集、外观全见过

Steam 玩家信息卡

每个玩家卡右上角显示头像/昵称/状态。数据来自开发者自建云服务（腾讯云、Cloudflare）查询 Steam 公开信息，无需 Steam 登录。

4. 保存与生效（关键！）

1
完全退出游戏（大退）

修改前先彻底关闭游戏（含 Steam 云同步）。游戏运行时内存里的进度会在退出时覆盖回存档文件——游戏开着时改等于白改。

2
先下载备份

建议点「下载备份」保存原始存档副本（带时间戳），改坏了随时还原。

3
修改并保存

「打开存档/目录扫描」方式载入 → 保存修改会弹窗确认后直接写回原文件并刷新页面；拖入方式则下载修改版，手动替换到 Saves 目录（文件名必须一致）。

4
重新启动游戏查看

修改要等下次进游戏才生效。

⚠️ 派生值会被游戏重算：最高岛（MaxIsland）、船解锁（UnlockedBoat）、雷达/烤架解锁、通关标志等是「派生显示值」，游戏保存时会按你的真实进度覆盖——改低基本无效。可持久修改的是物品实例属性（物品/皮肤/锋利度/配件）、金钱等。

5. 常见问题

改完游戏里看不到？

  1. 确认文件放回 Saves 目录且文件名完全正确（游戏只读「你的存档名.txt」，别存成 xxx(1).txt）
  2. 确认改的是进度档（WwW.txt 类型）而不是外观档
  3. 确认保存时游戏已完全退出（大退），保存后重启游戏
  4. 如果改的是派生值（岛屿/解锁类），被游戏重算是正常现象

Steam 资料卡一直灰色占位？

  1. 检查网络能否访问腾讯云 / Cloudflare 的服务
  2. Steam 账号隐私设置需允许公开查看个人资料，否则查不到
  3. 获取失败只影响资料卡显示，不影响存档编辑

本地文件会不会上传？

不会。存档内容全部在浏览器本地处理，只有玩家 SteamID 会发送到开发者的云服务查询公开头像/昵称（见页面说明）。

为什么文件是单行、没有格式？

游戏按单行紧凑 JSON 读取，工具保存时保持原格式，不要用记事本手动改格式。
